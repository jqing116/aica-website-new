# คลังภาพวิจัยและนวัตกรรมของจุฬา

ภาพใหม่ 30 ภาพ สำหรับเลือกใช้ประกอบเว็บไซต์ สไลด์ และสื่อสารงานวิจัยและนวัตกรรมของจุฬา ตามคำสั่งผู้ใช้วันที่ 7 กันยายน 2569

เปิด `index.html` เพื่อเลือกดูภาพตามหมวด ค้นหา และเปิดภาพเต็มขนาดได้

## สถานะและแนวทางใช้

- พร้อมเลือกใช้เป็นภาพประกอบตามธีม งานวิจัย นวัตกรรม และระบบสนับสนุนการวิจัย
- เป็นภาพสร้างด้วย AI ในแนวภาพถ่าย ไม่ใช่ภาพเหตุการณ์ บุคลากร หรือสถานที่จริงของจุฬา
- ใช้คำอธิบายเชิงภาพประกอบ ไม่ระบุชื่อคน หน่วยงาน ห้องปฏิบัติการ หรือเหตุการณ์จริงจากภาพ
- รูปคณะทำงานใช้สื่อบริบทการประชุม ห้ามใช้ยืนยันตัวบุคคลหรือองค์ประกอบคณะกรรมการจริง
- รูปคนใช้คอมพิวเตอร์ใช้สื่อบริบทการทำงาน ห้ามใช้แทนภาพหน้าจอ C2F, MyResearch, ONE IP หรือระบบอื่นเพื่อยืนยันความสามารถของระบบ
- เลือกหัวข้อที่ตรงกับภาพตามรายการ ไม่ใช้ภาพเดียวแทนหลายโครงการโดยไม่มีความเกี่ยวข้อง
- โทนภาพอ้างอิงแนวภาพถ่ายข่าวมหาวิทยาลัยของ [chula.ac.th](https://www.chula.ac.th/) และบรรยากาศ [การประชุมด้านวิจัยและนวัตกรรม](https://www.research.chula.ac.th/research-and-innovation-committee-meeting-2-2026/) เป็นแนวทางด้านสไตล์

## ไฟล์

- `originals/` ต้นฉบับ PNG 30 ภาพ ขนาดประมาณ 1.5 ล้านพิกเซล: 29 ภาพขนาด 1536 × 1024 และภาพโครงข่ายขนาด 1495 × 1052 พิกเซล
- `web/` WebP 30 ภาพ ขนาดเดียวกัน แปลงรูปแบบไฟล์เพื่อใช้งานบนเว็บ ไม่มีการเปลี่ยนองค์ประกอบภาพ
- `manifest.json` ชื่อภาพ หมวด บริบทการใช้งาน ขนาดไฟล์ และค่า SHA-256 ของต้นฉบับ
- `prompts.json` คำสั่งสร้างภาพแต่ละภาพ
- `index.html` แกลเลอรีแบบเปิดใช้งานในเครื่อง

## การตรวจและบันทึกงาน

สร้างภาพใหม่ครบ 30 ภาพ ตรวจภาพที่แสดงเต็มขนาด ตรวจจำนวน ความละเอียด การเปิดอ่านไฟล์ และไม่พบไฟล์ต้นฉบับซ้ำจากค่า SHA-256

การนำไปใช้กับตำแหน่งใดบนเว็บไซต์ให้เลือกภาพและตรวจการครอปตามบริบทอีกครั้ง
