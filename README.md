# AICA website: new About AICA page (draft)

A draft of the AICA (AI Competency Assessment) page for the Chula AI website. Not a finished or published site.

The page is short and is written for two visitors:

1. **About AICA**: what AICA is.
2. **For you**: what a working person does and gets.
3. **Five competency areas**.
4. **For your organization**: what an organization gets, who has used AICA, the five steps, and the contact.

## Files

- `index.html`: the page.
- `assets/site.css`: styles. The rules for this page are at the end of the file.
- `assets/intro.js`: page script (mobile menu, scroll effects).
- `assets/img/`, `assets/fonts/`: images and fonts.
